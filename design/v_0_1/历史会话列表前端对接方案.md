## 功能实现

### 1. 会话列表分页加载

```
┌─────────────────────┐
│  新对话按钮         │  ← 固定
├─────────────────────┤
│  会话列表           │  ← 可滚动
│  ├─ 会话1           │
│  ├─ 会话2           │
│  ├─ ...             │
│  └─ 加载更多...     │  ← 滚动到底部触发
└─────────────────────┘
```

- 首次加载 20 条
- 滚动到底部前 50px 自动加载下一页
- 显示"加载中"和"没有更多了"状态

### 2. 标题实时更新

SSE 事件流：
```
event: messages/partial    ← AI 回复内容
event: title_updated       ← 标题更新（新增）
event: end                 ← 流结束
```

前端处理：
```typescript
case 'title_updated':
  if (event.title && sessionStore.currentThreadId) {
    sessionStore.updateThreadTitle(sessionStore.currentThreadId, event.title)
  }
  break
```

### 3. 延迟创建会话

**问题**：之前点击"新对话"立即创建会话，导致大量空对话。

**解决方案**：
1. 点击"新对话" → `startNewSession()` 设置 pending 状态
2. 用户输入消息发送 → 检查是否有 threadId
3. 没有 threadId → 调用 `createSession()` 创建会话
4. 发送消息

```typescript
async function handleSend(message: string) {
  let threadId = sessionStore.currentThreadId
  
  if (!threadId) {
    threadId = await sessionStore.createSession()
  }
  
  if (threadId) {
    sendMessage(threadId, message)
  }
}
```

## 后端 API 对接

### GET /api/sessions

**请求参数：**
| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| page | int | 1 | 页码 |
| page_size | int | 20 | 每页数量 |

**响应：**
```json
{
  "threads": [
    {
      "thread_id": "user123-abc...",
      "title": "Python数据分析",
      "created_at": "2026-02-14T10:00:00",
      "message_count": 5,
      "status": "idle"
    }
  ],
  "total": 1
}
```

### SSE 事件 - title_updated

```
event: title_updated
data: {"title": "Python数据分析"}
```

## 注意事项

1. **会话列表固定**：左侧会话列表不随右侧内容滚动，独立滚动
2. **空对话优化**：只有真正发送消息才创建会话
3. **自动选择**：进入页面自动选择第一个历史会话
4. **深色模式**：所有组件都支持深色模式适配
5. **工具调用折叠**：默认收起，点击展开查看详情
